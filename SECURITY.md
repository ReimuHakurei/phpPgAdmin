# Security

Please don't open a public issue for security problems. Use GitHub's
"Report a vulnerability" button on the Security tab of this repo instead, so
it can be fixed before it's public.

Only the latest release and the Docker image built from it get fixes.

phpPgAdmin is old code and wasn't written with a hostile internet in mind.
Run it on a private network or behind authentication; see "About the image"
in README.md.
